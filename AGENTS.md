# Project Instructions

## Language policy

- Use English only throughout this repository.
- Do not add Chinese or any other non-English natural-language text.
- This rule applies to user interface copy, source comments, documentation,
  configuration, tests, fixtures, generated files, filenames, and packaged
  archives.
- Translate non-English source material into English instead of copying it into
  the repository.
- Before completing any change, scan for literal CJK characters, escaped CJK
  Unicode sequences, CJK filenames, generated output, and archive entries.
